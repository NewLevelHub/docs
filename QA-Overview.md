# QA — Overview

Процессы тестирования NewLevelHub.

---

## Окружение для тестирования

| Параметр | Значение |
|---|---|
| Staging URL | https://staging.newlevelhub.com |
| Swagger | https://staging.newlevelhub.com/docs |
| Тестовые аккаунты | Попроси у тимлида |

---

## Процесс QA

1. Тикет переходит в статус **Ready for QA**
2. QA проверяет Acceptance Criteria из тикета Linear
3. Тестирует на staging
4. **Pass** → статус **Done (QA Accepted)**
5. **Fail** → статус **Blocked (QA Fail)** → описывает баги в тикете → разраб фиксит в следующий рабочий день

---

## Что проверять в каждом тикете

- [ ] Все пункты AC выполнены
- [ ] Нет регрессии (старое не сломалось)
- [ ] Проверены edge cases
- [ ] Мобильная версия (если фронт)
- [ ] Ошибки в консоли браузера

---

## Как сообщать о багах

В тикете Linear в комментарии:

```
**Баг:** Что не работает
**Шаги:** Как воспроизвести
**Ожидалось:** Что должно быть
**Получилось:** Что есть сейчас
**Скриншот/видео:** (если есть)
```
