# Architecture — NewLevelHub

Общая схема системы NewLevelHub.

---

## Компоненты системы

```
                        ┌─────────────┐
                        │   Frontend  │  (Web)
                        └──────┬──────┘
                               │ HTTP / REST
                        ┌──────▼──────┐
                        │   Backend   │  Python / FastAPI
                        │             │
                        └──┬───┬───┬──┘
                           │   │   │
              ┌────────────┘   │   └────────────┐
              │                │                │
       ┌──────▼──────┐  ┌──────▼──────┐  ┌──────▼──────┐
       │  PostgreSQL  │  │    Redis    │  │   AI Service │
       │  (основная  │  │   (кэш,     │  │  (ML модели) │
       │    база)    │  │  очереди)   │  │              │
       └─────────────┘  └─────────────┘  └─────────────┘

       ┌─────────────┐
       │  IoT Service│  Go — данные с устройств
       │             │──────────────────────────► Backend
       └─────────────┘
```

---

## Репозитории

| Репо | Технология | Описание |
|---|---|---|
| `backend` | Python / FastAPI | Основной API сервис |
| `frontend` | — | Веб-клиент |
| `iot` | Go | Сервис IoT устройств |
| `ai` | Python | ML модели и обучение |
| `docs` | — | Документация (этот репо) |

---

## Окружения

| Окружение | Описание | URL |
|---|---|---|
| Local | Локальная разработка | localhost |
| Staging | Тестовое окружение | https://staging.newlevelhub.com |
| Production | Прод | https://newlevelhub.com |

## Технологический стек

| Слой | Технология |
|---|---|
| Backend | Python, FastAPI |
| Frontend | — |
| IoT | Go |
| AI / ML | Python |
| База данных | PostgreSQL |
